# Film-Vault

> **Unlocking cinema, one review at a time.**

Welcome to **Film-Vault**, my personal archive and diary where I log, rate, and write reviews for the movies I watch. 

---

##  About

Film-Vault serves as a centralized hub for all my thoughts on cinema,from timeless classics and hidden indie gems to the latest blockbuster releases. 

### Features
**Detailed Reviews:** Personal thoughts and hot takes on every movie logged.
**Star Ratings:** A quick, consistent grading system for every watch.
**Categorization:** Organized by genre, release year, and director.
**Favorites & Recommendations:** Highlighting the absolute best of the vault.

## Quick Start / Local Setup

To run this project locally on your machine:

```bash
# Clone the repository
git clone [https://github.com/Maya-alessia/Film-Vault.git](https://github.com/Maya-alessia/Film-Vault.git)

# Navigate into the project directory
cd Film-Vault

# Install dependencies
npm install

# Start the development server
npm run dev
